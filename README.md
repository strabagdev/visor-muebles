# Visor Muebles

Visor 3D para documentar y revisar muebles a medida.

## Estado actual

Primer modelo: **Isla comedor**

- 1500 × 700 × 900 mm
- patas 3×3" = 76,2 × 76,2 mm
- cubierta de 30 mm
- apoyapiés 2×2" = 50,8 × 50,8 mm
- vista isométrica y vistas ortogonales
- selección y aislamiento de piezas
- vista explotada
- despiece
- exportación CSV / JSON
- impresión a PDF

## Uso

Abre `index.html` en el navegador.

El visor carga Three.js desde CDN, por lo que necesita conexión a internet.

## Próximos pasos

La idea es sumar otros muebles al mismo repositorio y evolucionar este visor hacia una herramienta general de diseño y documentación.
